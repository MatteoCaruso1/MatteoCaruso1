### Hi, I'm Matteo 👋

I build apps / tools and ship them end to end: code, builds, releases.

**Public projects**

- **[NoteshAIre](https://github.com/MatteoCaruso1/noteshaire)**: a desktop app for piano practice. Set weekly goals, play, and it listens to your MIDI keyboard and fills the goals from what you actually played. Windows and Mac.
- **[Noteshare](https://github.com/MatteoCaruso1/noteshare)**: the first version, a music practice journal for musicians, live at [notesharemusic.com](https://notesharemusic.com). A web app built with React, Supabase and Stripe.
- **[Lockout](https://github.com/MatteoCaruso1/lockout)**: a strict iPhone app blocker with no way out. Once a lock starts, only time ends it. SwiftUI and Apple's Screen Time APIs, built and shipped without a Mac.
- **[Fantasy hockey board](https://github.com/MatteoCaruso1/fantasy-hockey-board)**: a weekly decision board for Yahoo fantasy hockey: player model, best nightly lineups, add/drop plan and a trade market that models what other managers will accept.

Plus a series of private projects.
